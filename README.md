# Wireshark Basics - Network Traffic Analysis Lab

This repository documents my hands-on practice and learning outcomes from completing the **"Wireshark: The Basics"** room on TryHackMe.

The lab focuses on understanding packet analysis, network traffic inspection, and basic digital forensics techniques using Wireshark.

---

## 🎯 Objectives

- Learn how to navigate packet captures.
- Understand protocol layers and packet structures.
- Apply display filters for efficient traffic analysis.
- Extract files from network captures.
- Validate data integrity using hashes.
- Follow TCP and HTTP streams.
- Identify useful artifacts inside network traffic.

---

## 🧰 Tools Used

- Wireshark
- Linux Terminal
- TryHackMe Lab Environment
- Command Line Utilities (md5sum, strings, grep)

---

## 🔍 Skills Practiced

- Packet dissection (Ethernet, IP, TCP, HTTP)
- Display filtering
- Stream analysis
- File extraction from packet captures
- Hash validation
- Traffic inspection
- Network troubleshooting
- Digital forensics fundamentals
